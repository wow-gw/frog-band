# 🐸 물개구리 밴드 — 선곡 · 오디션 · 멤버 관리 시스템

물개구리 밴드 멤버들이 함께 **연주할 곡을 고르고, 오디션을 평가하고, 멤버 정보를 관리**하는 웹 앱이에요.
스마트폰이나 PC의 인터넷 브라우저에서 바로 열어서 사용할 수 있어요.

---

## 📂 파일 구성

```
frog-band/
│
├── band-vote-sheets.html   ← 🌟 메인 앱 파일 (이 파일을 브라우저로 열어요)
├── index.html              ← 소개 페이지
│
├── css/
│   ├── band.css            ← 앱의 색상·디자인 담당
│   └── index.css           ← 소개 페이지 디자인
│
└── js/
    └── app.js              ← 앱의 모든 기능 (버튼 동작, 저장, 불러오기 등)
```

> 💡 **비유하자면:** `html` 파일은 집의 뼈대, `css` 파일은 인테리어, `js` 파일은 전기·수도 같은 실제 작동 부분이에요.

---

## 🖥️ 사용 방법

**`band-vote-sheets.html`** 파일을 브라우저(크롬, 엣지 등)로 열면 바로 시작돼요.
별도 설치나 회원가입 없이 사용할 수 있어요.

## 📱 탭별 기능 설명

### ➕ 곡추가
연주하고 싶은 후보곡을 등록해요.
- 아티스트, 곡 제목, 장르, 세션/보컬 난이도, 제안자 이름을 입력
- **🐸 후보곡 추가** 버튼을 누르면 목록에 올라가요

### 🗳️ 투표
등록된 후보곡에 점수를 매겨요.
- 먼저 **내 포지션(보컬, 기타 등)을 선택**한 뒤 투표
- 🔥 꼭해야해 (5점) · 👍 괜찮아 (3점) · 😐 글쎄 (1점)

### 🏆 결과
투표 점수를 합산해서 순위를 보여줘요.
- 난이도 밸런스(세션+보컬)와 투표 참여 인원을 함께 고려한 종합 점수
- 상위 4곡이 자동으로 **선정 후보**로 표시돼요

### 🎤 오디션
특정 곡의 보컬 후보들을 평가해요.
- 유튜브 영상 URL을 등록하면 앱 안에서 바로 재생
- 음정/감성/무대매너 3가지 항목을 별점(⭐ 1~5점)으로 평가
- 최고 점수를 받은 후보에게 👑 표시

### 🧑‍🎤 멤버
밴드 멤버 정보를 관리해요.
- 이름, 포지션, 한마디 수정 가능
- 프로필 사진 업로드 가능

### 📅 히스토리
지금까지 밴드가 연주한 곡들의 기록이에요.
- 완료된 곡은 초록 점(●), 중도 하차한 곡은 회색 점으로 표시

### ⚙️ 설정
구글 시트 연동 주소(URL)를 등록하는 곳이에요. *(아래 참고)*

## 💾 데이터 저장 방식

이 앱은 데이터를 **두 곳**에 저장해요.

| 저장 위치 | 역할 | 특징 |
|---|---|---|
| **구글 시트** | 모든 멤버가 함께 보는 공용 저장소 | 인터넷 연결 필요, 어떤 기기에서도 같은 데이터 |
| **브라우저 내부 (localStorage)** | 내 기기 전용 임시 저장소 | 인터넷 없어도 유지, 구글 시트 연결 실패 시 백업 |

> 구글 시트 연동이 되어 있으면 → 시트가 기준  
> 연결이 안 될 때 → 내 브라우저에 저장된 데이터를 자동으로 사용해요

---

## 🔗 구글 시트 연동 설정 (최초 1회)

앱의 데이터를 구글 시트에 저장하려면 아래 순서로 진행해요.

1. **구글 시트 새로 만들기** → [sheets.new](https://sheets.new)
2. 상단 메뉴 → `확장 프로그램` → `Apps Script` 클릭
3. 받은 `apps-script.js` 내용을 전체 붙여넣고 저장 (`Ctrl+S`)
4. `배포` → `새 배포` → 유형: `웹 앱` → 액세스: `모든 사용자` → 배포
5. 생성된 **웹 앱 URL**을 앱의 ⚙️ 탭에 붙여넣고 **🐸 연결하기** 클릭

> ✅ 한 번 연결하면 이후에는 자동으로 저장돼요.

## ❓ 자주 묻는 질문

**Q. 앱을 열었는데 곡 목록이 비어있어요**  
A. 구글 시트 연결에 실패했거나, 시트에 저장된 곡이 없는 거예요. ⚙️ 탭에서 URL이 제대로 입력되어 있는지 확인해보세요.

**Q. 추가한 곡이 새로고침 후 사라졌어요**  
A. 구글 시트 저장에 실패했을 가능성이 높아요. 화면 오른쪽 아래에 `❌ 저장 실패` 메시지가 잠깐 떴다면, ⚙️ 탭에서 연결 상태를 확인해주세요.

**Q. 다른 사람은 내가 추가한 곡이 안 보여요**  
A. 구글 시트가 연동되어 있어야 여러 명이 같은 데이터를 볼 수 있어요. 연동 없이 사용하면 내 브라우저에만 저장돼요.
