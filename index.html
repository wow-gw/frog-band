⚙️ Google Sheets 연동 설정

앱 데이터를 구글 시트에 저장하려면 아래 순서대로 진행해주세요. 딱 한 번만 하면 돼요!

1
Google Sheets를 새로 만들어요
👉 sheets.new 바로가기
2
상단 메뉴 → 확장 프로그램 → Apps Script 클릭
3
받은 apps-script.js 내용을 전체 붙여넣고 저장(Ctrl+S)
4
배포 → 새 배포 → 유형: 웹 앱
액세스: 모든 사용자 선택 후 배포 클릭
5
생성된 웹 앱 URL을 아래에 붙여넣기 후 연결!
